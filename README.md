MovieVerse
Production-ready Online Movie Ticket Booking System built with Java, Spring Boot, React, AWS, and Microservices concepts.

Tech Stack

Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT

Frontend
- React
- Redux Toolkit
- Material UI

Cloud
- AWS EC2
- AWS RDS
- AWS S3
- Docker
- GitHub Actions

Features
- User Authentication
- Movie Management
- Theatre Management
- Seat Booking
- Payment Integration
- Ticket Generation
- Email Notifications
- Admin Dashboard
